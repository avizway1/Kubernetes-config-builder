# v1.1.0

**Learning Kubernetes made easy** by [Aviz Academy](https://avizacademy.com). The lessons and labs from v1.0.0, under their new name.

## Start it

```sh
git clone https://github.com/avizway1/learning-kubernetes-made-easy.git
cd learning-kubernetes-made-easy
docker compose up -d
```

Open [localhost:8080](http://localhost:8080). Docker pulls `ghcr.io/avizway1/learning-kubernetes-made-easy:v1.1.0` for Linux AMD64 or ARM64. You can also download `compose.yaml` from this release and run `docker compose up -d` from its folder. New to Docker? The [start guide](https://github.com/avizway1/learning-kubernetes-made-easy/blob/v1.1.0/README.md#start-learning) starts from a laptop with nothing installed, on macOS, Windows, and Linux.

Already cloned the project? Run `git pull`, then `docker compose up -d`.

## What's new

- The project is now **Learning Kubernetes made easy - Aviz Academy**, at [github.com/avizway1/learning-kubernetes-made-easy](https://github.com/avizway1/learning-kubernetes-made-easy). Old links to the repository still work.
- The dashboard image is about 23 MB. It holds only the lessons, labs, and setup page, and a small server that shows them.
- Your saved setup check and lab ticks reset once, because the dashboard now stores them under its new name. Paste the check's output on **Set up your laptop** again to unlock the labs.

## Known limits

- CI checks the Windows setup commands in Ubuntu on WSL 2, but nobody has yet tried Docker Desktop's WSL integration or Lab 1 on a Windows laptop.
- A development-only picomatch finding is an accepted risk until its review on 2026-12-02. It is not in the Docker image.
