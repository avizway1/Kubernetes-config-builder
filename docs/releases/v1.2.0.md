# v1.2.0

**Learning Kubernetes made easy** by [Aviz Academy](https://avizacademy.com). Setting up your laptop now ends with a practice cluster that kubectl is pointed at, so your first Try it reaches it.

## Start it

```sh
git clone https://github.com/avizway1/learning-kubernetes-made-easy.git
cd learning-kubernetes-made-easy
docker compose up -d
```

Open [localhost:8080](http://localhost:8080). Docker pulls `ghcr.io/avizway1/learning-kubernetes-made-easy:v1.2.0` for Linux AMD64 or ARM64. You can also download `compose.yaml` from this release and run `docker compose up -d` from its folder. New to Docker? The [start guide](https://github.com/avizway1/learning-kubernetes-made-easy/blob/v1.2.0/README.md#start-learning) starts from a laptop with nothing installed, on macOS, Windows, and Linux.

Already cloned the project? Run `git pull`, then `docker compose up -d`.

## What's new

- **Set up your laptop** is the first item in the lesson list, before Level 0. It opens with what your laptop needs.
- **Step 6** creates your practice cluster once, then gives two commands to run every time you practise: `kubectl config use-context k3d-practice` and `kubectl get nodes`. If kubectl shows an error, **If something goes wrong** gives the exact message and the command that fixes it.
- **Every Anywhere lesson's Try it** starts with the same switch command, so kubectl talks to your practice cluster even after you have used another one.
- **Every Try it command has a Copy button**, and commands show `--` as two dashes.
- **Step 7, Look inside your practice cluster**, is optional. It opens a shell on the practice cluster's node with `docker exec` and shows, without changing anything, where Kubernetes keeps its data, certificates, and logs.
- The start guide gives the same steps.
- Your saved setup check and lab ticks carry over from v1.1.0.

## Known limits

- CI checks the Windows setup commands in Ubuntu on WSL 2, but nobody has yet tried Docker Desktop's WSL integration or Lab 1 on a Windows laptop.
- A development-only picomatch finding is an accepted risk until its review on 2026-12-02. It is not in the Docker image.
