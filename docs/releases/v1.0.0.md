# v1.0.0

The first release of **Kubernetes Made Simple** by [Aviz Academy](https://avizacademy.com), and the first from this repository. It completes phase 1, **Learn Kubernetes**.

## Start it

```sh
git clone https://github.com/avizway1/Kubernetes-config-builder.git
cd Kubernetes-config-builder
docker compose up -d
```

Open [localhost:8080](http://localhost:8080). Docker pulls `ghcr.io/avizway1/kubernetes-config-builder:v1.0.0` for Linux AMD64 or ARM64. You can also download `compose.yaml` from this release and run `docker compose up -d` from its folder. New to Docker? The [start guide](https://github.com/avizway1/Kubernetes-config-builder/blob/v1.0.0/README.md#start-learning) starts from a laptop with nothing installed, on macOS, Windows, and Linux.

## What's new

- **36 lessons in Levels 0 to 8**, from reading YAML to autoscaling and Pod Identity. Each lesson builds a real file one block at a time, explains every block in plain English, and shows a note for every line on hover. 29 lessons run on a free k3d practice cluster. 7 need Amazon EKS with Auto Mode.
- **Read it and Fix it practice** at the end of every lesson. Every error message the practice shows was captured from kubeconform, K3s 1.37.2, or EKS Auto Mode.
- **Try it** commands from *Parts of every manifest* onwards, checked on K3s and on an EKS Auto Mode 1.37 cluster.
- **Lab 1 · Hello Kubernetes** runs an app on your laptop for free. **Lab 2 · Your app on EKS** runs the same app on EKS Auto Mode with a load balancer, an EBS disk, and Pod Identity, then deletes everything. Each lab opens with a lesson on its files, then walks you through its commands with a Copy button on each.
- **Set up your laptop** checks your tools with one command and unlocks each lab when its tools are ready. On Windows, labs run in Ubuntu on WSL 2.
- The dashboard opens straight into Learn Kubernetes. **Build a config**, the Argo CD and Prometheus builder from v0.4.0, is hidden until phase 2 and still opens at [localhost:8080/#build](http://localhost:8080/#build).
- Docker needs 4 GB of memory, down from 8 GB, because you no longer build the image yourself. Building from source is in [Contributing](https://github.com/avizway1/Kubernetes-config-builder/blob/v1.0.0/docs/contributing.md#build-the-docker-image-from-source).

## Known limits

- CI checks the Windows setup commands in Ubuntu on WSL 2, but nobody has yet tried Docker Desktop's WSL integration or Lab 1 on a Windows laptop.
- Accepted risks, reviewed on their dates: a development-only picomatch finding on 2026-12-02, and findings in the Argo CD and Prometheus chart images, including Dex, on 2026-12-11. None of them affects the lessons or labs.
