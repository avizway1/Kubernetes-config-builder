# v1.3.0

**Learning Kubernetes made easy** by [Aviz Academy](https://avizacademy.com). One script for your system now installs every tool the lessons and labs need.

## Start it

```sh
git clone https://github.com/avizway1/learning-kubernetes-made-easy.git
cd learning-kubernetes-made-easy
docker compose up -d
```

Open [localhost:8080](http://localhost:8080). Docker pulls `ghcr.io/avizway1/learning-kubernetes-made-easy:v1.3.0` for Linux AMD64 or ARM64. You can also download `compose.yaml` from this release and run `docker compose up -d` from its folder. New to Docker? The [start guide](https://github.com/avizway1/learning-kubernetes-made-easy/blob/v1.3.0/README.md#start-learning) starts from a laptop with nothing installed, on macOS, Windows, and Linux.

Already cloned the project? Run `git pull`, then `docker compose up -d`.

## What's new

- **One install script per system** in [scripts](https://github.com/avizway1/learning-kubernetes-made-easy/tree/v1.3.0/scripts): `install-macos.sh`, `install-windows.ps1`, and `install-linux.sh` for Ubuntu and Debian. You download yours with one command, before you clone anything.
- Each script first prints your system, CPU, architecture, cores, memory, and free disk. It stops on a system or chip the lessons don't support, and warns below 8 GB of memory or 10 GB of free disk.
- It then installs only what is missing: Docker, Git, kubectl v1.37.2, k3d, the AWS CLI, and eksctl, with each tool's official commands. On Windows it installs Git, Docker Desktop, and Ubuntu on WSL 2, then runs the Linux script inside Ubuntu. Running it again is safe: it skips what is installed.
- It ends with the setup check and prints the lines to paste into step 4.
- It never accepts an agreement, signs in to AWS or Docker, or changes your settings. Docker Desktop's agreement and AWS sign-in stay with you.
- **Step 3 of Set up your laptop** opens with your system's script, with a Copy button and a link to read it. The step-by-step cards for each tool are still below, under **Or install each tool yourself**.
- The start guide gives the same script as **The quick way**, before step 1.
- Your saved setup check and lab ticks carry over from v1.2.0.

## Known limits

- CI runs the scripts on macOS (Apple silicon and Intel), on Windows with Ubuntu on WSL 2, and in Ubuntu and Debian containers. CI runners can't run Docker Desktop, so nobody has yet installed Docker Desktop with the macOS or Windows script on a real laptop.
- The macOS runners already had the AWS CLI and Git, so the macOS script's AWS CLI and Git installs haven't run yet.
- Nobody has yet tried Docker Desktop's WSL integration or Lab 1 on a Windows laptop.
- A development-only picomatch finding is an accepted risk until its review on 2026-12-02. It is not in the Docker image.
