## Older prebuilt release

`docker compose up -d` without the build file pulls the v0.4.0 image, `ghcr.io/cavula/kubernetes-config-builder:v0.4.0`. It has the Argo CD and Prometheus builder and the GitOps and monitoring lab, but not Kubernetes Made Simple or the lessons. To get the lessons, build from source as the [README](../../README.md#start-learning) shows.
