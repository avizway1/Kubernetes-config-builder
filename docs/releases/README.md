## Images

From v1.0.0, release images are published to `ghcr.io/avizway1/kubernetes-config-builder`, and `compose.yaml` pulls the latest release. The older images, up to `ghcr.io/cavula/kubernetes-config-builder:v0.4.0`, have the Argo CD and Prometheus builder but not Kubernetes Made Simple or the lessons.
