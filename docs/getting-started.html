Run Learning Kubernetes made easy on your laptop

This guide takes you from a laptop with nothing installed to the Learn Kubernetes lessons open in your browser. Copy each command, paste it into your terminal, and press Enter.

What this is. Learning Kubernetes made easy is a website that runs on your own laptop. It teaches Kubernetes one small block at a time and explains every line in plain English.

Why Docker. Docker runs the website inside a sealed box called a container, so you don't have to install its programming tools yourself. You install Docker once, and one command downloads and starts everything.

✓

Check your laptopTwo minutes

  • Memory: 8 GB of RAM or more. Docker uses half of it, which is enough for the dashboard and a practice cluster.
  • Disk: about 10 GB free, to be safe.
  • Internet: a steady connection. The first start downloads the dashboard, and the practice cluster downloads Kubernetes.
  • Permission to install apps. On a work laptop you may need IT's help.

To check your memory, open the Apple menu, then About This Mac. The Chip line also tells you which Docker download you need: Apple M… means Apple silicon, Intel means Intel.

To check your memory, open Settings → System → About and look at Installed RAM. Docker Desktop needs 64-bit Windows 10 (22H2) or Windows 11 (23H2 or later), Pro, Enterprise, or Education.

To check your memory, run free -h and look at the total column.

Opening a terminal. A terminal is a window where you type commands. Press Cmd + Space, type Terminal, and press Enter. Click Start, type PowerShell, and open Windows PowerShell. Every command in this guide works there. Open your distribution's Terminal app. To paste, use Cmd + VCtrl + V or a right-clickCtrl + Shift + V.

1

Install DockerAbout 10 minutes

  1. Open Docker Desktop for Mac and download the installer for your chip: Apple silicon or Intel chip.
  2. Double-click Docker.dmg and drag Docker into Applications.
  3. Open Docker from Applications, then select Accept on the subscription agreement. Docker won't start until you accept.
  4. Wait until the whale icon in the menu bar stops moving.
  1. Open Docker Desktop for Windows and download Docker Desktop Installer.exe.
  2. Run the installer. On the configuration page, keep Use WSL 2 instead of Hyper-V selected.
  3. Select Close when it finishes, and restart Windows if it asks.
  4. Open Docker Desktop from Start, then accept the subscription terms. Docker won't start until you accept.

WSL is the Windows feature Docker runs on. If Docker says WSL needs an update, run this in PowerShell, then reopen Docker Desktop:

wsl --update
  1. Install Docker Engine for your distribution with the official Docker Engine instructions. It includes the Compose plugin.
  2. Follow the post-install steps so you can run docker without sudo.

Work laptops: Docker Desktop is free for personal use, education, and businesses with fewer than 250 employees and under $10 million in yearly revenue. Larger companies need a paid Docker subscription, so check with your IT team.

Check that Docker works 
docker version
docker compose version

You should see version details for both a Client and a Server, then a Docker Compose version. If you see “Cannot connect to the Docker daemon”, Docker isn't running yet: open Docker Desktop and wait a minute.

2

Check Docker's memoryOne minute

The dashboard and a practice cluster use about 2 GB together, so Docker needs 4 GB or more. Docker gets half your laptop's memory by default, so an 8 GB laptop is already enough.

Check how much memory Docker has 
docker info | grep "Total Memory"
docker info | Select-String "Total Memory"
docker info | grep "Total Memory"

You should see Total Memory: 3.5GiB or more. Docker shows memory in GiB, which reads a little lower than GB. If it's lower, give Docker more:

  1. Click the Docker whale in the menu bar and open Settings.
  2. Go to Resources → Advanced.
  3. Set Memory limit to 4 GB or more, then select Apply & restart.

On Windows, Docker uses the memory that WSL allows, which is half your laptop's memory by default.

  1. Open WSL Settings from the Start menu and set the memory size to 4 GB or more.
  2. Quit Docker Desktop, run the command below in PowerShell, then open Docker Desktop again.
wsl --shutdown

Docker Engine can use all of your laptop's memory, so there is nothing to change. If you use Docker Desktop for Linux, set Settings → Resources → Advanced → Memory limit to 4 GB or more.

3

Install GitFive minutes

Git downloads the project and, later, its updates.

macOS installs Git with Apple's Command Line Tools. Run this and select Install in the window that appears. If it says the tools are already installed, you're done.

xcode-select --install

Run this in PowerShell, then close PowerShell and open a new one so it finds Git. You can also use the Git for Windows installer.

winget install --id Git.Git -e --source winget

Use your package manager. On Ubuntu or Debian:

sudo apt install git
Check that Git works 
git --version

You should see a line such as git version 2.x.

Can't install Git? Download the project as a ZIP file and unzip it into your home folder. The folder is called learning-kubernetes-made-easy-main, so use that name in the cd commands below and skip the git clone line. To update later, download the ZIP again.

4

Download and start the dashboardA few minutes

Make sure Docker Desktop is running, then paste these four lines into your terminal. They are the same on every laptop.

cd ~
git clone https://github.com/avizway1/learning-kubernetes-made-easy.git
cd learning-kubernetes-made-easy
docker compose up -d
  • cd ~ goes to your home folder.
  • git clone downloads the project into a new learning-kubernetes-made-easy folder.
  • docker compose up -d downloads the dashboard and starts it in the background.

You should see Docker download the dashboard, then a line that says Started. The download happens only the first time.

Open it and start learning

Open http://localhost:8080 in your browser. localhost means your own laptop: nothing is sent anywhere else.

You land on Learn Kubernetes. At the top, Set up your laptop says what your laptop needs, installs the tools, and points kubectl at a practice cluster. Do it before your first Try it. Then start with Level 0 · Reading YAML and click Start on Read a YAML file.

After Level 1, try Lab 1 · Hello Kubernetes from Hands-on labs at the bottom of the lesson list. It runs a small app on your laptop in about 15 minutes, for free. Do Set up your laptop, at the top of the lesson list, first: it checks the tools from step 6 and unlocks each lab when they're ready.

6

Optional: a practice cluster for Try itFree, runs inside Docker

A cluster is where Kubernetes runs your files. k3d creates a small one inside Docker, and kubectl is the command you use to talk to it.

Install them with Homebrew. If brew --version doesn't work, first install Homebrew with the command on brew.sh.

brew install k3d
brew install kubectl

On Windows, the practice cluster and the labs run in Ubuntu on WSL 2, a Linux terminal built into Windows. Docker Desktop already runs on WSL 2.

  1. Open PowerShell as administrator and run the command below. It installs Ubuntu, and WSL too if Docker Desktop hasn't. Restart when it asks, then Ubuntu asks you to choose a user name and password.
wsl --install -d Ubuntu
  1. In Docker Desktop, open Settings, then Resources, then WSL integration. Turn on Ubuntu and select Apply & restart.
  2. Open Ubuntu from the Start menu. Run every command from here on in Ubuntu, not PowerShell.

See Microsoft's Install WSL and Docker's WSL 2 backend guides. Then, in Ubuntu, install k3d with the official installer. Read it, then run it.

curl -fsSL -o install-k3d.sh https://raw.githubusercontent.com/k3d-io/k3d/main/install.sh
bash install-k3d.sh

Install kubectl 1.37.2 from the official Linux instructions. On an ARM64 laptop, replace amd64 with arm64.

curl -LO "https://dl.k8s.io/release/v1.37.2/bin/linux/amd64/kubectl"
curl -LO "https://dl.k8s.io/release/v1.37.2/bin/linux/amd64/kubectl.sha256"
echo "$(cat kubectl.sha256)  kubectl" | sha256sum --check
sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl

Download the official k3d installer, read it, then run it.

curl -fsSL -o install-k3d.sh https://raw.githubusercontent.com/k3d-io/k3d/main/install.sh
bash install-k3d.sh

Install kubectl from the official Linux instructions.

Create the practice cluster, once 
k3d cluster create practice --image rancher/k3s:v1.37.2-k3s1 --wait

You should see Cluster 'practice' created successfully near the end. k3d adds the cluster to your kubeconfig, the file kubectl reads to find clusters, and switches kubectl to it.

Point kubectl at the practice cluster

kubectl sends every command to one cluster: the current context in your kubeconfig, ~/.kube/config. Check it before each Try it, and after Lab 1, Lab 2, or an EKS only lesson, which use other clusters.

Check which cluster kubectl uses 
kubectl config current-context
kubectl get nodes

You should see k3d-practice, then one node named k3d-practice-server-0 with STATUS Ready.

If it prints another name or current-context is not set, switch to the practice cluster. With no current context, kubectl tries localhost:8080, which is the dashboard, and says the server could not find the requested resource.

Switch to the practice cluster 
kubectl config get-contexts
kubectl config use-context k3d-practice

You should see Switched to context "k3d-practice".

If k3d-practice isn't in the list but k3d cluster list shows practice, add it back to your kubeconfig and switch to it. See k3d's kubeconfig guide.

k3d cluster list
k3d kubeconfig merge practice --kubeconfig-merge-default --kubeconfig-switch-context

Try your first file

In the lesson Run one container, click Show whole file, then Download. Your browser saves pod.yaml in your Downloads folder. Then run:

In Ubuntu, your Windows Downloads folder is /mnt/c/Users/<your Windows user name>/Downloads. Use that path instead of ~/Downloads.

cd ~/Downloads
kubectl apply -f pod.yaml
kubectl get pod web

You should see pod/web created, then STATUS Running after a few seconds. Each lesson's Try it panel lists the next commands.

Level 5 needs three nodes. When you reach it, add two worker nodes 
k3d node create worker --cluster practice --role agent --replicas 2 --image rancher/k3s:v1.37.2-k3s1 --wait
kubectl get nodes

You should see three nodes with STATUS Ready. Every other lesson works with one node or three.

When you finish, delete the practice cluster 
k3d cluster delete practice

Everyday commands

Run these from the project folder. Docker Desktop must be running.

Start it again, for example after restarting your laptop 
cd ~/learning-kubernetes-made-easy
docker compose up -d

It starts in seconds, because Docker keeps the dashboard it downloaded.

Get the latest lessons 
cd ~/learning-kubernetes-made-easy
git pull
docker compose up -d

If there's a new release, Docker downloads it first. Then reload the page with Cmd + Shift + RCtrl + Shift + RCtrl + Shift + R.

Check whether it's running 
docker compose ps
Stop it 
docker compose down
Remove it completely 
docker compose down --rmi all

This stops the dashboard and deletes the image it downloaded. Then delete the learning-kubernetes-made-easy folder from your home folder.

?

If something goes wrong

“docker: command not found” or “Cannot connect to the Docker daemon”

Docker isn't installed or isn't running. Open Docker Desktop, wait until it says it's running, then try again. On Windows, close PowerShell and open a new one after installing.

“no configuration file provided: not found”

The terminal isn't in the project folder. Run cd ~/learning-kubernetes-made-easy first, or the -main folder name if you used the ZIP.

“port is already allocated” or “address already in use”

Another program already uses port 8080. Find it with the command below, close that program, then start the dashboard again.

lsof -i :8080
netstat -ano | findstr :8080
sudo lsof -i :8080
“fatal: destination path 'learning-kubernetes-made-easy' already exists”

You already downloaded the project. Skip the git clone line and use Get the latest lessons above.

localhost:8080 doesn't load

Run the Check whether it's running command. If nothing is listed, start it again. If the first download is still running in your terminal, wait for it to finish.

The page looks old after an update

Your browser kept an earlier copy. Reload once with Cmd + Shift + RCtrl + Shift + RCtrl + Shift + R.

“Unable to connect to the server” from kubectl

The practice cluster isn't running. Run k3d cluster list. If it's missing, create it again with the command in step 6.
